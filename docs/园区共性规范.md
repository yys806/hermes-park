# 园区模型·共性规范（2026-10-29 用户定）

适用于全部 12 块地块。每块建模/返工的提示词都必须带上这份规范。

## 一、传送带样式统一

用户原话：「各个场景的传送带的样式要统一，就是后续这些都是要接起来的，场景内部就只需要样式统一就行了，宽度可以不统一，但是汇总的那个必须 9 个都统一。」

### 汇总段（Belt_Hub_ / Belt_Main_ / Port_Main_）——全园 9 块必须完全一致
- 带面宽度 **0.90 m**，带面高 **0.55 m**（离地）
- 带面厚 0.06 m，深灰 #5A5F66
- 两侧挡边高 0.12 m、厚 0.04 m，浅灰 #A8ADB3
- 支腿方柱 0.08×0.08 m，间距 1.5 m，底部垫板 0.20×0.20×0.04，深灰 #8C9196
- 接口法兰：1.00×1.00 m 方环，厚 0.05，四角各一颗螺栓，色 #B4B9BF
- 汇总段末端一律朝**正南**，出地块边界前 1.0 m 处收口

### 场景内部子带（Belt_Sub_ / Port_<实体>）——样式统一、宽度可按负载调整
- 带面宽度 0.6–0.9 m 任选，但同一块地内必须一致
- 其余（厚 0.06、挡边 0.12/0.04、支腿 1.5 m 间距、法兰尺寸、配色）与汇总段完全相同
- 带面要有横向滚筒纹：每 0.12 m 一道浅槽，槽深 0.008

### 命名
`Port_<实体>` → `Belt_Sub_<实体>` → `Belt_Hub_<区域>` → `Belt_Main_<区域>` → `Port_Main_<区域>`

## 二、灯：只有灯罩发光

用户原话：「pi 和 claude 的灯就是整个灯都在发亮，我要的只是灯这一部分发亮就行了，杆子这些都不许发光。」

- **发光体**：只有灯罩/灯泡，对象名 `LGT_<灯名>` 或 `LGT_<灯名>_shade/_globe/_bulb/_head/_lantern`
- **灯具实体**：灯杆、底座、帽、环箍、支架，命名 `LGT_<灯名>_post/_pole/_foot/_base/_cap/_collar/_arm/_bracket/_frame/_body`
  —— 这些部件的材质**自发光一律为 0**，用普通哑光材质
- 一盏灯**只放一个点光源**，位置在灯罩中心
- 室内灯 `castShadow=true`；室外路灯 `castShadow=false`

## 三、内部灯与外部灯的分工

用户原话：「中央这里的内部也要有一点灯的，其他地块就外部有灯就行了，但是不要太多，要协调。」

- **中央大厅 control**：室内 3–4 盏（环形轨道内侧两盏 + 操作台上方一盏 + 中枢台座顶光一盏），室外 4–5 盏
- **其他 11 块**：只做室外灯（沿路、门口），每块 3–5 盏，不设室内灯
- 灯的数量以"能照亮主要动线"为准，不要铺满

## 四、不要为了凑体量而硬凑

用户原话：「不要为了达到 15mb 而硬凑，现在就是有几个就是有种为了硬凑而做的感觉，我只是说要达到前两个模型的标准。」

- **禁止**用细分（subdivide）、加面片、堆无意义小方块来抬面数和体积
- 达标的判断标准是**零件密度**：网格对象 ≥ 250 个、其中窗框/栏杆/瓦垄/拉手/支架/层板/抽屉/台阶/檐口/屋脊这类小件占比 ≥ 0.25
- 标杆：家人事务 507 网格 / 181 零件，学习科研 164 网格（早期标杆）、日常生活 148 网格
- 加分项是"装出来的"：窗有窗框+窗台+窗棂+玻璃分格，门有门框+门板分块+门把+门槛，
  屋顶有瓦垄+檐口+屋脊，地面铺装分块有缝有路缘石，家具带腿/抽屉/拉手/螺栓

## 五、闪烁（z-fighting）

用户原话：「好多模型内部还是有好多闪烁的地方，就是一拖动就闪烁。」

已知修法（详见 skill threejs-web-scene 第十节）：
- **框件必须跨过洞口边缘往墙里埋 0.02–0.03**，绝不能和洞口切面共面
- 装饰线条（踢脚/腰线/檐口）整体外移 0.012
- 合页/把手/铭牌平贴墙面时外移 0.012
- 构件底面正好等于地板顶面时抬高 0.005
- 建模脚本 join 前跑共面检测：同一轴坐标差 < 0.004 且另两轴投影重叠 → 报警（同材质跳过）

查看器侧近远比已压到 1:9，剩下的都是几何共面，必须建模侧修。

## 六、三个外协吉祥物（Claude / Pi / Codex）

用户原话：「我就只要一个具体的这个东西，不要别的装饰啥的」。

- **只保留本体 + 一块干净的薄地台 + 一盏地灯**；键盘、纸堆、终端机、标记牌、电线、散落物一律不许有
- **Claude（Clawd）**：橙红方块小螃蟹，四短腿、两侧张开的双瓣蟹钳、竖黑点眼睛，棱边大倒角但轮廓方正
- **Pi**：三块低饱和色块拼成 P（鲑鱼粉倒 L + 浅蓝块 + 淡黄竖条），块状几何，缝隙可见
- **Codex**：**一个整体的、立起来的圆形云朵**——六个柔和突起长在同一张连续曲面上，正反两面中间最厚、向四周递减（双凸透镜），
  白色 `>_` 贴正面平整区中央，不许压在棱上；必须轴对称 + 中心对称。
  做法：metaball 六球等角度等半径 + 中心球 → 融合 → 转网格 → Remesh + Smooth → 按半径做厚度衰减

## 七、交付前的验收清单（每块都过一遍）

1. 包围盒符合尺寸表（常规 16×16、外协 20×20、中央 25×25）
2. 网格数 ≥250、小件占比 ≥0.25（外协单体除外）
3. 灯：只有灯罩发光；室外 3–5 盏（中央另有室内 4 盏）
4. 传送带：汇总段 9 块完全一致（0.90 宽、0.55 高、朝南）
5. 无共面闪烁：框件埋进 0.02–0.03、贴面件外移 0.012
6. glb 由我独立导出并解析核对，不采信 agent 自报
