# 园区业务驾驶舱 · 怎么用（2026-10-31 凌晨版）

> 打开：http://127.0.0.1:8788/viewer2/index.html
> 旧的模型库仍在：http://127.0.0.1:8788/viewer/
> 首次打开可能 15–21 秒（GPU 着色器冷启动），第二次起约 6 秒。

## 一、基本操作

| 想做 | 怎么做 |
|---|---|
| 转视角 | 左键拖动旋转 / 右键平移 / 滚轮缩放 |
| 聚焦某块地 | 点它（或点左栏任一条任务，会自动飞过去） |
| 回全景 | 顶部「全景」按钮 / 双击空白 / R 键 |
| 看某个建筑 | 聚焦后点它上方的圆形编号徽标（如「② 实验室」） |
| 换环境 | 顶部：手动/跟随 · 春夏秋冬 · 日间夜间 · 晴阴雨雪 · 低中高画质 |

## 二、右侧三栏（点地块后出现）

- **职责**：这个群管什么、能接什么、不接什么；下面列分区，每个分区一句话。
- **此刻**：正在跑的任务、接下来三个任务、本区任务数与成功率。
- **待办 · Cron**：
  - 待办前面有 ✓ 按钮，点了会**真的把云表状态改成已完成**（有二次确认概念，但目前是直接写）。
  - Cron 每条右侧有「报告」和「重跑」；报告是那一轮的完整输出原文，重跑会排进执行队列。
- **资料**：资产管理→资产台账，彩虹事务→彩虹出路，日常事务→影视清单。**密码类字段一律打码**，右上角可跳飞书原表。

底部还有「模型参数」折叠块，需要看三角面数这类数据时再展开。

## 三、左栏

- 今日待办 15 条 + Cron 49 个，每条前面是地块徽标（学习 / 彩虹 / 资产…）。
- 点任一条 → 相机飞到对应地块。
- 待办右侧 ✓ 与右栏是同一个动作。
- 左上角「‹」可以把整栏收起。

## 四、跟随模式

点顶部「跟随」后，页面会：
1. 读真实时间（每秒刷新）；
2. 拉上海嘉定的实况天气（10 分钟缓存，拉不到显示「离线」）；
3. 按经纬度算太阳高度角与方位角，影子方向跟着太阳走；
4. 日出日落自动切昼夜，过渡 3–5 秒，夜里灯逐盏亮。

## 五、会动的两样东西

1. **包裹**：只有 cron 任务真的在跑的时候，传送带上才有货箱走，并被目标地块的进度环标示；任务结束包裹回中央、环淡出。没任务时园区是干净的。
2. **进度环**：悬在地块上方缓慢旋转，就是"这块地在忙"。

## 六、已知问题（早上先知道）

1. **首次打开慢**：着色器冷启动，二次即恢复；要治可做预热。
2. **分区徽标只有 7 块地有**：`资产管理` 和 `咨询新闻` 的模型节点名不是 `Obj_*`（资产是 `m:VA_*`、新闻是 `Obj_AITower_1..8` 分片），需要补一份节点映射表才能出徽标。
3. **业务流（多轮聚合）还没做**：现在只显示"正在跑 / 接下来"，没有"第 2/4 步"那种。
4. **点 ✓ 会直接写云表**，撤销要走 `/api/todo/undo`（界面上还没挂按钮）。

## 七、出问题怎么查

- 页面打不开：`curl http://127.0.0.1:8788/api/health`，返回 `{"ok":true}` 就是服务活着。
- 服务挂了：在 `D:/hermes/home` 下执行 `node server/server.js`（或让我重启）。
- 数据不更新：看 `D:/hermes/home/cache/api/` 下的缓存文件时间戳。
- 验收脚本：`D:/hermes/home/tmp_scripts/` 里 `final_check.py`（全量）、`p2_test.py`（三栏）、`hs_test.py`（分区徽标）、`cargo_test2.py`（包裹）。
