# 园区总场景 viewer2（2026-10-30 上线）

把 12 个 glb 接成一个完整园区的最终版预览页。**独立于模型库**：`viewer/` 一个文件都不许改。

## 打开

- 总场景：http://127.0.0.1:8788/viewer2/index.html （静态服务器根目录 = `D:/hermes/home`，`server/server.js` 常驻）
- ⚠️ 不要用临时起的 `python -m http.server 8765`：那是 agent 调试用的一次性服务，会随会话结束消失，页面会打不开。验收脚本已统一指向 8788。
- 模型库（原样保留）：http://127.0.0.1:8788/viewer/

## 文件

| 文件 | 作用 |
|---|---|
| `viewer2/index.html` / `style.css` | 页面与 UI |
| `viewer2/scene.json` | 地块坐标 / 名称 / glb 路径 / 传送带连接关系（改布局只改这里） |
| `viewer2/park.js` | 加载、材质合批、阴影、昼夜、悬停与点击 |
| `viewer2/belts.js` | 传送带生成（曲线 + 法兰 + 支腿 + 滚轮纹 + 货箱动画） |
| `viewer2/world.js` | 草地、步道、树林（程序化，约 4100 棵树 + 1100 块石头） |

## 布局

- 中央大厅 `control` 在原点，正面朝 +Z。
- 8 块功能地块 45° 一圈，半径 31 m，正面朝中央，地块边到大周边 10.3–10.5 m。
- 3 块外协在资产管理（vault，位于 −Z 方向）侧面外侧，±48° 扇形，各自一条带子接进 vault 背面的法兰。
- 传送带汇总段规格按 `docs/园区共性规范.md` 第一节：带面宽 0.90、顶面高 0.55、厚 0.06、挡边 0.12×0.04、支腿 0.08 每 1.5 m、法兰 1.00 方环四角螺栓。

## 模型侧的约定（必须保持一致，否则带子会起伏）

- 每块地的 `Port_Main_<地块名>` 法兰中心 / 带面顶面 = **离地 0.55 m**（2026-10-30 已统一，改前 0.30–0.75 乱跳）。
- `vault` 背面有三个出线法兰 `Port_Main_vault_A/B/C`，本地 x = −5.5 / 0 / +5.5，z = −8.32 / −8.06 / −8.32。
- 三块外协（`clawd` / `pi` / `codex`）模型里没有 Port 节点，接入点按 18 m 圆盘边缘算（`round: 9.4`）。
- 中央大厅一侧的接点用 `Track_<方向>_belt.ct` 节点（glb 里点号会被 GLTFLoader 去掉）。

## 坑

- **agent 自报导出成功不可信**：它会报"已导出 35 MB"，磁盘上却没有文件；导出统一由 Hermes 用 `blender -b` 独立进程做。
- **后台模式切场景会失败**：`w.window.scene = sc` 在 `-b` 模式下可能静默失效，导致导出成别的地块（曾把四个场景的对象混进一块，45 MB）。`scripts/export_scene_glb.py` 改成**先删掉其它场景再导出**。
- **transmission 材质会在 three.js 里多渲一遍全场**：inventor 的玻璃已换成普通半透明。
- 12 块合计约 7.4 M 三角面、5000+ draw call，必须按材质合批（降到约 900 批），否则帧率崩。
